# Third-party runtime components

- GLFW: zlib/libpng license, included in GLFW.txt.
- stb_truetype: Sean Barrett, MIT license, included in stb_truetype.txt.
- Roboto Mono Nerd Font: copyright and full font licenses in assets/fonts/.
- VMA: AMD, MIT license, included in VMA.txt. Header-only integration currently.
- macOS MoltenVK: Apache 2.0, included in MoltenVK.txt.
- Windows/Linux Vulkan loader: Apache 2.0, included in Vulkan-Loader.txt.

Operating-system libraries and GPU drivers remain platform prerequisites.
